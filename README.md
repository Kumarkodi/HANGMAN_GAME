# Hangman Game

A classic Hangman word guessing game built using HTML, CSS, and JavaScript.

## Overview

**Hangman Game** offers a fun and interactive way to play the traditional hangman game in your browser. Try to guess the hidden word one letter at a time before the hangman drawing is completed!

## Features

- Interactive keyboard for guessing letters
- Random word and hint selection from a word list
- Visual hangman drawing that updates with incorrect guesses
- Game over and win animations
- Responsive and user-friendly design

## How to Play

1. A random word and hint are displayed.
2. Click on the on-screen keyboard to guess letters.
3. Each incorrect guess adds a part to the hangman drawing.
4. Guess the word before the full hangman is drawn to win!

## Project Structure

```
HANGMAN_GAME/
├── images/         # Hangman images and game gifs
├── index.html      # Main HTML file
├── script.js       # Game logic
├── style.css       # Game styles
└── wordList.js     # List of words and hints
```

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Kumarkodi/HANGMAN_GAME.git
   ```
2. **Open `index.html` in your browser to start playing.**
3. https://kumarkodi.github.io/HANGMAN_GAME/

## Customization

- Add or edit words and hints in `wordList.js` to increase the game's vocabulary.
- Replace or add new images in the `images/` folder for a personalized look.
